## 本地卡片管理台（admin/）

- 需求：本地维护 pages 里的卡片，不做上线部署，改完同步 GitHub + 更新 CloudBase。
- 架构：零依赖 Node 后端 `admin/server.js`（端口 8787）+ 原生 HTML 前端 `admin/index.html`，支持 music/video 两模块的**增删改 + 排序 + 批量输入**。
- 启动：`node admin/server.js` → 浏览器开 `http://localhost:8787`。
- 接口：`GET /api/raw?m=music|video` 返回 pages 原文 JSON；`POST /api/save` 收 `{module, gridHtml}`，用 `replaceModuleGrid` 配对替换 `#moduleGrid` 内部（保留外层 div，写前自动备份 `.bak`）。
- 批量输入格式：music 每行一个 file.garden 链接（默认以文件名作标题）；video 每行一个 `<iframe src="...">` 片段或 `player.bilibili.com` 链接（自动提取 src、补齐 `https:`）。
- `replaceModuleGrid` 用 div 深度配对定位闭合标签，再 `inner.trim()` 包裹换行，保证 round-trip 无损（实测 video 无损、music 新增成功）。
- **CloudBase 上线时只传 pages/ 等正式文件，不要传 admin/ 目录**（本地工具，含写盘逻辑，不应暴露到线上）。
